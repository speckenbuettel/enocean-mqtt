# Golden Registry Baselines

This directory contains canonical reference registry JSON files generated by the EEP compiler.

Purpose:

- detect unintended compiler regressions,
- detect semantic registry changes,
- validate stable telegram normalization,
- validate stable channel semantics,
- validate deterministic telegram identifiers.

Recommended baseline profiles:

- D2-01-00
- F6-02-01
- A5-20-06
- A5-04-02
- D5-00-01

Suggested workflow:

1. Generate registry JSON files using the compiler.
2. Compare generated output against the golden baseline.
3. Explicitly review semantic changes before updating baselines.

The golden baselines intentionally represent:

- runtime semantics,
- normalized telegram structures,
- deterministic compiler output,
- channel classification,
- dependency resolution.
